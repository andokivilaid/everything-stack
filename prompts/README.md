# Agent prompts

Paste these into any coding agent (Claude Code, Codex, Cursor…) opened in this repo.

| Prompt | Use it to |
|---|---|
| [`kickoff.md`](kickoff.md) | Start a new product from the template (same as `/everything`) |
| [`finalize-and-test.md`](finalize-and-test.md) | **Maintainers:** test every path with real accounts, fix what breaks, finalize the GitHub repo |
| [`matrix-test.md`](matrix-test.md) | Maintainers: exercise non-default stack combinations |
| [`add-feature.md`](add-feature.md) | Add a real feature to an app built from the template |
| [`go-live.md`](go-live.md) | Take a finished app to production |
